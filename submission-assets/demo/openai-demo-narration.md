# MCP Queen OpenAI demo narration

## 0:00 — MCP Queen

MCP Queen helps developers find MCP servers, inspect current operational evidence and Trust Receipts, and decide what to connect.

## 0:10 — Developer Mode setup

This is the MCP Queen plugin connected to its universal, no-auth production endpoint in ChatGPT Developer Mode.

## 0:30 — Find a server by task

MCP Queen searches by the developer's task and returns matching servers with endpoints, operational grades, dated observations, and caveats.

## 1:10 — Inspect an operational grade

The grade breakdown exposes the observations behind each point. It measures observable operational behavior and is not a security certificate.

## 1:42 — Search tools by capability

Tool-level search identifies the specific capabilities developers need and keeps each result connected to its server, endpoint, and evidence.

## 2:20 — Inspect a Trust Receipt

Trust Receipts keep operational observations separate from security, data integrity, citations, claims, benchmarks, and field evidence. Missing evidence is labeled unaudited.

## 3:02 — Reviewed field evidence

Existing field reports come from real server use and are human reviewed. They are published as qualitative evidence, never counted as votes, and never directly change the operational grade.

## 3:38 — Current operational leaderboard

The leaderboard is a current operational comparison, not a universal safety ranking.

## 4:08 — Field-report safety boundary

MCP Queen rejects feedback based only on search results. A report must describe actual use and enters a quarantined human-review queue.

## 4:35 — Discovery on iOS

The same evidence-backed discovery workflow is available in ChatGPT on iOS.

## 5:00 — Trust evidence on Android

On Android, the Trust Receipt preserves the same distinction between observed evidence and unaudited dimensions.

## 5:25 — Find. Verify. Connect.

MCP Queen is the evidence layer for MCP. Find, verify, then connect directly to the server.
